# [OnUseGear](https://github.com/ktkr3d/OnUseGear)

## Introduction

OnUseGear is an add-on for usable gear.

## Install

1. Install MyUsableItems using the [WowUp](https://wowup.io/guide/get-addons/overview) app.

  ```text
  https://github.com/ktkr3d/OnUseGear
  ```

## Configuration

```text
/oug - Open configuration GUI
```

## Toggle lock state

```text
/oug lock - Toggle lock state
```
